# three/disasters/

Disaster-specific visualization layers. Each plugs into the common 3D scene (three/core, three/scenes) — the scene never depends on a specific disaster module.

- flood/ — rising water level, inundation extent
- cyclone/ — wind field, track, storm-surge impact
- tsunami/ — wave propagation, arrival time, coastal inundation
- oil-spill/ — slick/particle movement, weathering
- pollution/ — concentration plume rendering
