# tests/ — Cross-Domain Tests

Integration/e2e/contract tests spanning multiple domains. Domain-local unit tests stay in each domain's own tests/ folder (frontend/tests, backend/tests, simulation/tests, agents/tests, rag/tests).

- integration/ — multi-domain integration tests
- e2e/ — Playwright end-to-end browser tests
- fixtures/ — shared test fixtures
- contracts/ — tests validating shared/ contracts stay honored
